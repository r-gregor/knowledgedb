Regex in bash parameter expansion
Wen, 2026-11-18

The parameter expansion´s substitution doesn´t work with regular expressions. extglob can help, but it doesn´t
work with regular expressions, either.
$> shopt -s extglob

extglob provides some mechanisms similar to regex with (from bash man page):
          ?(pattern-list)
                 Matches zero or one occurrence of the given patterns
          *(pattern-list)
                 Matches zero or more occurrences of the given patterns
          +(pattern-list)
                 Matches one or more occurrences of the given patterns
          @(pattern-list)
                 Matches one of the given patterns
          !(pattern-list)
                 Matches anything except one of the given patterns
