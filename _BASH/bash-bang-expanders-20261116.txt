When repeting bash commands or arguments -- bang-expanders:

                        (!*)
               _________________________
              ´                         `
$>  command   param1    param2    param3
   |                              `_____´
   |                              (!$)  |
   `____________________________________´
                (!!)

!! - whole command
!* - all the arguments to a command
!% - the last argument to a command
