Series of PNG files to a PDF
2026/08/01

   I have a bunch of PNG scans I want to make into a single PDF.

   Using Debian Linux.
$> sudo apt update
$> sudo apt ugrade -y
$> sudo apt install img2pdf

   My file names are of the form 01.png, 02.png ... 12.png, named like this so that they list in the
   correct order.

   I run:
$> img2pdf -o Unipol-Major-manual.pdf ??.png

   And it looks good, but when I view the PDF, 2 of the pages are too small, and img2pdf gave this error
   code twice - it seems that 2 of the images were produced in a slightly different way from the others:
Image contains an alpha channel. Computing a separate soft mask
(/SMask) image to store transparency in PDF.

   If I try to convert them to TIFF files using convert, I can see which files it is, and get a
   different error message:
$> for f in ??.png ; do convert $f $f.tiff ; done
convert: sBIT: bad length `03.png' @ warning/png.c/MagickPNGWarningHandler/1527.
convert: sBIT: bad length `05.png' @ warning/png.c/MagickPNGWarningHandler/1527.

   If I web search for BIT: bad length, I find:
   https://yuceltoluyag.github.io/en/png-mogrify-chunk-hatalari-cozumu/

   I back up all my PNG files to a new folder and:
$> mogrify -strip -quality 100 ??.png
$> img2pdf -o Unipol-Major-manual.pdf ??.png

   No error message! PDF looks great. On the other hand, it is 24 MB. I know there are various things to
   think about when shrinking PDFs (downsampling and so on), but I just did this:
$> pdf2ps Unipol-Major-manual.pdf temp.ps
$> ps2pdf temp.ps Unipol-Major-manual.pdf

   Now it s under 4 MB. Looks much the same. All good.
