How do you guys switch workspace.

Sorry, this post was deleted by the person who originally posted it.

The default config should have these as 1. Mod enter, 2. Mod + any number and 3. Mod + Shift + target
workspace number.

***
Personally, I have this custom scheme: 
  * If more than one tile on workspace, Alt+Tab switches through them 
  * If only single tile, Alt+Tab switches to next workspace
  * Even if tiles >1, Super+Tab switches workspaces back and forth 
  * Super+L/RArrows move forward or back through the workspaces freely 
  * Super+Number works as default
  * Super+Shift+Number works as default

There might be more, I´m not sure

bindsym $mod+Right focus right

On workspace_logic.sh (the code is AI btw):

#!/bin/bash
DIRECTION="$1"

TREE=$(i3-msg -t get_tree)

# Current workspace
CURRENT=$(echo "$TREE" | jq '[recurse(.nodes[]?, .floating_nodes[]?) | \
select(.type=="workspace" and (.nodes[]?.focused==true or .floating_nodes[]?.focused==true))][0].num')

# Fallback: Get focused workspaces via get_workspaces (more reliable)
CURRENT=$(i3-msg -t get_workspaces | jq '.[] | select(.focused).num')

# Lists the con_ids of all windows (leaves) in the current workspace in TREE ORDER (DFS).
WINDOW_IDS=($(echo "$TREE" | jq -r "  \
	recurse(.nodes[]?, .floating_nodes[]?) \
	| select(.type == \"workspace\" and .num == $CURRENT) \
	| [recurse(.nodes[]?, .floating_nodes[]?) | select(.window != null) | .id] \
	| .[]
"))

WINDOW_COUNT=${#WINDOW_IDS[@]}

# Get ordered workspace numbers
WORKSPACES=($(i3-msg -t get_workspaces | jq '.[].num' | sort -n))

# Find current workspace index
INDEX=0
for i in "${!WORKSPACES[@]}"; do
	if [ "${WORKSPACES[$i]}" = "$CURRENT" ]; then
		INDEX=$i
		break
	fi
done

TOTAL=${#WORKSPACES[@]}

if [ "$WINDOW_COUNT" -le 1 ]; then
	# Only one window (or none): switch workspace
	if [ "$DIRECTION" = "next" ]; then
		NEW_INDEX=$(( (INDEX + 1) % TOTAL ))
	else
		NEW_INDEX=$(( (INDEX - 1 + TOTAL) % TOTAL ))
	fi
	TARGET=${WORKSPACES[$NEW_INDEX]}
	i3-msg workspace number "$TARGET"
else
	# Multiple windows: find the focused one and jump to the next/previous one in the tree.
	FOCUSED_ID=$(echo "$TREE" | jq " \
		[recurse(.nodes[]?, .floating_nodes[]?) | select(.window != null and .focused == true)][0].id
	")

	WIN_INDEX=0
	for i in "${!WINDOW_IDS[@]}"; do
		if [ "${WINDOW_IDS[$i]}" = "$FOCUSED_ID" ]; then
			WIN_INDEX=$i
			break
		fi
	done

	if [ "$DIRECTION" = "next" ]; then
		NEW_WIN_INDEX=$(( (WIN_INDEX + 1) % WINDOW_COUNT ))
	else
		NEW_WIN_INDEX=$(( (WIN_INDEX - 1 + WINDOW_COUNT) % WINDOW_COUNT ))
	fi

	TARGET_ID=${WINDOW_IDS[$NEW_WIN_INDEX]}
	i3-msg "[con_id=$TARGET_ID] focus"
fi

Let´s assume:
I´m on workspace 1 (default one: mod+1): start new terminal (mod+enter)
switch to workspace 2 (mod+2): open browser (and if I want to go back last workspace (1) I press mod+b to
switch and mod+shift+b for moving open browser to last workspace (1)

workspace_auto_back_and_forth yes
bindsym Mod4+b workspace back_and_forth
bindsym Mod4+Shift+b move container to workspace back_and_forth; workspace back_and_forth

When I start session I will open every workspaces by launching on them terminal so every workspace already
available; and 'Alt+space exec --no-startup-id rofi -show window' to switch to available windows by searching
by the title of the window or by workspace´s names

***
Just 'rofi -show window' and type something; right now I have 46 browser (brave) window opened and 1 firefox;
on brave I have also Vimium extension where I press shift+t to search on tabs across all open windows; I think
this is way more easier than just looking for what you needed by Alt+tab or manually searching every open
workspaces

which I still use today and is worth your time trying. You can bind the two key sequence $mod+digit $mod+digit
to visit a workspace but in the past I have used the number pad eg KP_2 KP_6 gets workspace 26 . You could
have 100 workspaces this way but for one handed operation you might only bind digits 1 to 5 so you don´t have
to stretch but it still gives you 25 (5x5) workspaces.

If you bind just 3 function keys that´s still 3x3=9 workspaces, 3 more function keys cover move container to
workspace.
