google query2: rofi i3 windows and workspaces switcher with $mod+w
Here is how you can set up Rofi to switch between both windows and workspaces using $mod+w.
Since the default rofi -show window command only shows open windows, we can use an excellent, highly optimized
tool called rofi-i3-blocks (or a clean Python utility) to give you a unified, searchable switcher for both
elements.

Step 1: Install i3ipc
First, ensure you have the required Python library to talk to i3´s API:
$> pip install i3ipc
# Or via your package manager (e.g., sudo apt install python3-i3ipc or pacman -S python3-i3ipc)

Step 2: Create the Switcher Script
Create a new file at ~/.config/i3/rofi-switcher.py:
$> mkdir -p ~/.config/i3
$> nano ~/.config/i3/rofi-switcher.py

Paste the following script into it. It grabs all your current workspaces and open windows, lists them in Rofi,
and handles switching back to them:

#!/usr/bin/env python3
import subprocess
import i3ipc

i3 = i3ipc.Connection()
options = {}

# 1. Gather Workspaces
for ws in i3.get_workspaces():
	name = f"📁 Workspace: {ws.name}"
	options[name] = f"workspace {ws.name}"

# 2. Gather Windows
for node in i3.get_tree().leaves():
	if node.type == 'con' and node.name and node.workspace().name != '__i3_scratch':
		name = f"🖥️  [{node.workspace().name}] {node.name}"
		options[name] = f"[con_id={node.id}] focus"

# 3. Pass to Rofi
rofi_input = "\n".join(options.keys())
rofi = subprocess.Popen(
	["rofi",r"-dmenu", "-p", "Go to", "-i"],
	stdin=subprocess.PIPE,
	stdout=subprocess.PIPE,
	text=True
)
stdout, _ = rofi.communicate(input=rofi_input)
selected = stdout.strip()

# 4. Execute choice
if selected in options:
	i3.command(options[selected])

Make the script executable:
$> chmod +x ~/.config/i3/rofi-switcher.py

Step 3: Bind to $mod+w in i3
Open your i3 configuration file (~/.config/i3/config) and add the keybinding:

# Launch the combined window and workspace switcher
bindsym $mod+w exec --no-startup-id ~/.config/i3/rofi-switcher.py

Note: If $mod+w was previously assigned to something else (like layout tabbed/stacked), make sure to comment
      out or delete that old binding.

Step 4: Refresh i3
Reload your i3 configuration to apply the changes by hitting $mod+Shift+r. Now, pressing $mod+w will open a
fuzzy-searchable list showing all workspaces and windows together.

You can use rofi´s built-in window mode or write a custom script using i3-msg / i3ipc to switch between i3
windows and workspaces seamlessly.

1. Using Rofi´s Built-in Window Switcher
Rofi has a native window mode that lists all open windows across your workspaces.

Add this binding to your i3 configuration file (~/.config/i3/config):
bindsym $mod+d exec rofi -show window

* How it works: Press $mod+d (or your preferred shortcut) to open a searchable list of all open windows.
  Selecting a window instantly switches to its workspace and focuses it.

2. Creating a Custom Workspace Switcher Script
If you want a dedicated menu just for switching workspaces (rather than individual windows), you can use a
small script with i3-msg and rofi -dmenu.

Create a script named i3_switch_workspaces.sh:

#!/usr/bin/env bash
# Get a list of workspaces using i3-msg, parse names, and pass to rofi
chosen=$(i3-msg -t get_workspaces | jq -r '.[].name' | rofi -dmenu -p "Workspace")

# If a workspace was chosen, switch to it
if [ -n "$chosen" ]; then
	i3-msg workspace "$chosen"
fi

Make the script executable:
$> chmod +x i3_switch_workspaces.sh

Add this binding to your ~/.config/i3/config:
bindsym $mod+Tab exec --no-startup-id /path/to/i3_switch_workspaces.sh

* Prerequisites: This requires jq to parse the JSON output from i3-msg.

additional query: I want a combined menu that shows both workspaces and windows at the same time

To create a combined menu that lists both workspaces and individual windows at the same time, you can use a
custom bash script. The script queries i3-msg for your open windows and active workspaces, formats them nicely
into a single list, and passes them to rofi -dmenu.

Here is how to set it up:
1. Create the Combined Switcher Script
Create a new file named ~/.config/i3/rofi-i3-switcher.sh and paste the following code:

#!/usr/bin/env bash

# Check for dependencies
if ! command -v jq &> /dev/null; then
	echo "Error: 'jq' is required but not installed." >&2
	exit 1
fi

# 1. Fetch data from i3
workspaces_json=$(i3-msg -t get_workspaces)
tree_json=$(i3-msg -t get_tree)

# 2. Extract and format active workspaces
workspaces=$(echo "$workspaces_json" | jq -r '.[] | "📁 Workspace: \(.name)"')

# 3. Extract and format open windows (excluding scratchpads/special containers)
windows=$(echo "$tree_json" | jq -r ' \
.. | select(.window? != null and .focused? == false or .focused? == true) | \
"🪟 [\(.window_properties.instance // "Unknown")] \(.window_properties.title // .name)" \
')

# 4. Combine lists and present via Rofi
chosen=$(printf "%s\n%s" "$workspaces" "$windows" | rofi -dmenu -i -p "Switch to")

# 5. Handle the user selection
if [ -n "$chosen" ]; then
	if [[ "$chosen" =~ "📁 Workspace:" ]]; then
		# Extract workspace name and switch
		ws_name=$(echo "$chosen" | sed 's/📁 Workspace: //')
		i3-msg workspace "$ws_name"
	elif [[ "$chosen" =~ "🪟" ]]; then
		# Extract the window title (or partial title) to focus it
		# We strip the emoji and instance prefix to match the title
		win_title=$(echo "$chosen" | sed -E 's/🪟 \[[^]]+\] //')
		i3-msg "[title=\"$win_title\"] focus"
	fi
fi

2. Make the Script Executable
Open your terminal and run:
$> chmod +x ~/.config/i3/rofi-i3-switcher.sh

3. Bind it in Your i3 Config
Add the following line to your ~/.config/i3/config file to bind the script to a keyboard shortcut (e.g.,
$mod+Tab or $mod+d):
bindsym $mod+Tab exec --no-startup-id ~/.config/i3/rofi-i3-switcher.sh

4. Refresh i3
Restart i3 in place by pressing $mod+Shift+r. Now, when you trigger the shortcut, you will see a unified list
showing your workspaces prefixed with 📁 and windows prefixed with 🪟.
