Vim: How to open another [No Name] buffer?
Dec 18, 2010

There are many ways to open a new buffer with no name, the simplest of which is :new:
:new              will create a split window with an unnamed buffer
:enew             will open one in the current window
:vnew             will open one in a vertically split window
:tabnew           will open one in a new tab
:e filename       will open filename in new buffer
:split filename   will open filename in new buffer in new h-split window
:vsplit filename  will open filename in new buffer in new v-split window

--
Commands to Open New Buffers:
:enew             Opens a brand new, empty, unnamed buffer in your current window
:edit filename    Opens a specified file into a new buffer in the current window
:e filename       Opens a specified file into a new buffer in the current window
:new filename     Opens a new file or empty buffer in a horizontal split window
:vnew filename    Opens a new file or empty buffer in a vertical split window
:tabnew filename  Opens a new file or empty buffer in a brand new tab page
