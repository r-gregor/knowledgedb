How to empty your hidden Linux trash folders to reclaim space: My 2 favorite ways
October 21, 2026

   Linux drive running out of space? You might have a lot of trash hidden away that you can delete to
   fix that.

   Today, I needed to copy a video clip from my rendering station to my main desktop. When I attempted
   to do so, I was warned that there wasn´t enough space for a 6 GB file.

   So, I set out to delete as much as I could to free up some space, but it didn´t seem to show up.

   Then I remembered there were some hidden trash folders that can sometimes collect files without
   deleting them.

What are the folders in question?
   The primary culprit is ~/.local/share/Trash, which can take up a fair amount of drive space. That
   folder is where deleted files go when removing them either from the terminal or using a GUI. That
   folder contains three subfolders:
     * files/ - this stores the actual deleted files and folders.
     * info/ - this stores small text files, including the information for where each file was
       originally housed and when it was deleted
     * expunged/ - this is used as a temporary location for when files are actively being emptied or
       deleted from the trash.

   Other folders include:
     * ~/.local/share/flatpak/appstream - if you use Flatpak, this can contain several subfolders for
       app trash from Flatpak apps installed for the user only.
     * /var/lib/flatpak/appstream/* - this Flatpak trash folder is for apps installed system-wide.
     * ~/snap/<app name>/common/.local/share/Trash/files - where Snap apps send their trash (where <app
       name> is the name of the app in question.

   I´m going to show you how to delete the files in those folders, but we´re going to use two different
   methods for it, both of which are run from the command line.

trash-cli
   The first method is done via a command line tool that is geared specifically for emptying
   files/folders from the ~/.local/share/Trash folder, as well as any trash folders found in connected
   external drives.

   Before you can use this tool, you have to install it, which is done with one of the following
   commands:
     * Debian/Ubuntu: $> sudo apt-get install trash-cli -y
     * Fedora:        $> sudo dnf install trash-cli -y
     * Arch:          $> sudo pacman -S trash-cli

   To use the app, all you have to do is type the command:
$> trash-empty

   This will ask you to verify the emptying of all the discovered Trash folders for your user. Type y
   and hit Enter on your keyboard.

   The app doesn´t show how much space it cleared, since it´s pretty basic.

   That app took care of those folders, but not the others. Here´s how we´ll empty them.

rm -rf
   Good old rm -rf. This is a very powerful command, so please use it with caution. If you´re a bit
   nervous about it, drop the f option (which is for force), and you´ll be prompted to confirm whether
   you want to delete every file and folder found.

   Let´s clear out those folders. Here are the commands to use:
$> rm -rf ~/.local/share/Trash
$> rm -rf ~/.local/share/flatpak/appstream/
$> rm -rf /var/lib/flatpak/appstream/*

   Once you´ve done all of the above, you should have recovered a pretty good amount of space (assuming
   those folders have been collecting trash for a while).

   Hopefully, that will reclaim some space. If it doesn´t return enough to you, consider opening your
   desktop´s Disks utility (such as GNOME Disks), which should give you a good indication of what is
   gobbling up that space.
